# Nestory

Nestory is a home inventory that helps you remember what you own and where you stored it.

**Live website:** https://nestoryhome.netlify.app/

## Features

- Search and filter saved items by room.
- Browse an interactive floor map and room directory.
- Add rooms and storage spots, then rename them as your home changes.
- Add, edit, and remove inventory items.

## Run locally

Open `index.html` in a web browser. No build tools or package installation are required.

## Data and privacy

Nestory currently stores profile, room, and inventory data in the browser's local storage. Data does not sync between browsers or devices, and the local profile is not an online account.
